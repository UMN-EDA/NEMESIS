# NEMESIS GitHub Pages Site

This directory contains the static website for the NEMESIS framework documentation.

## Files

- `index.html`: main GitHub Pages page.
- `styles.css`: visual styling and responsive layout.
- `script.js`: mobile navigation behavior.
- `assets/`: copied OTA topology figures used by the site.

## GitHub Pages Setup

In the GitHub repository settings:

1. Open **Settings**.
2. Open **Pages**.
3. Set **Source** to deploy from a branch.
4. Select the branch you push to, usually `main`.
5. Select `/docs` as the publishing folder.

The website is static and does not require a build step.
