# Executable OTA Models

The `ota_model_stageN.py` files are scalar Python evaluators compiled from the corresponding structured LLM outputs. `design_sizer.py` imports each one to estimate circuit performance, optimize device operating points, and then verify the equations with operating-point values extracted from HSPICE.

Stages 1 through 8 are intermediate hypotheses retained for audit and comparison. `ota_model_stage9.py` is the converged scalar model. `ota_model_stage9_vectorized.py` is the post-convergence batch evaluator generated for faster evaluation of arrays of design points; it does not replace SPICE as the source of verification truth.

The `__pycache__/` directory contains interpreter-generated bytecode only. It is safe to omit when publishing or copying the example.
